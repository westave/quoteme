# QuoteMe - Система сбора ставок от экспедиторов

Современное веб-приложение для сбора и сравнения ставок от экспедиторов на транспортно-экспедиционное обслуживание.

## Особенности

### Для импортера:
- Создание грузов с детальной информацией (маршрут, инкотермс, даты, виды транспорта)
- Одобрение/отклонение заявок экспедиторов
- Просмотр всех ставок от экспедиторов
- Закрытие грузов и раскрытие всех ставок

### Для экспедитора:
- Самостоятельная регистрация по ИНН компании
- Просмотр доступных грузов
- Подача нескольких ставок на один груз
- Просмотр заблюренных ставок конкурентов до закрытия груза
- После закрытия груза - доступ ко всем ставкам всех участников

### Технический стек

**Backend:**
- Node.js + Express
- TypeScript
- PostgreSQL
- Prisma ORM
- JWT аутентификация
- bcryptjs для хеширования паролей
- Zod для валидации данных

**Frontend:**
- React 18
- TypeScript
- Vite (сборщик)
- Tailwind CSS
- React Router v6
- Axios
- Zustand (управление состоянием)
- date-fns (работа с датами)

## Установка и запуск

### Требования

- Node.js 18+
- PostgreSQL 14+
- npm или yarn

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd quoteme
```

### 2. Настройка базы данных

Создайте PostgreSQL базу данных:

```bash
createdb quoteme
```

### 3. Настройка Backend

```bash
cd backend

# Установка зависимостей
npm install

# Создайте .env файл
cp .env.example .env

# Отредактируйте .env и укажите параметры подключения к БД
# DATABASE_URL="postgresql://user:password@localhost:5432/quoteme?schema=public"
# JWT_SECRET="your-secret-key-change-this-in-production"
# PORT=3001

# Применить миграции Prisma
npx prisma migrate dev --name init

# Генерация Prisma Client
npx prisma generate

# Запуск в режиме разработки
npm run dev
```

Backend будет доступен на `http://localhost:3001`

### 4. Настройка Frontend

```bash
cd frontend

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

Frontend будет доступен на `http://localhost:3000`

### 5. Production сборка

**Backend:**
```bash
cd backend
npm run build
npm start
```

**Frontend:**
```bash
cd frontend
npm run build
# Файлы сборки будут в директории dist/
```

## Использование

### Первичная настройка

1. **Создание аккаунта импортера:**
   - Используйте POST запрос к `/api/auth/register/importer`
   - Или создайте напрямую в БД

2. **Регистрация экспедитора:**
   - Откройте `/register`
   - Заполните форму с указанием ИНН компании
   - Аккаунт перейдет в статус "Ожидает активации"

3. **Активация экспедитора:**
   - Войдите как импортер
   - Перейдите на вкладку "Экспедиторы"
   - Одобрите или отклоните заявки

### Workflow

1. **Импортер создает груз:**
   - Указывает все параметры груза
   - Выбирает доступные виды транспорта
   - Устанавливает дедлайн подачи ставок

2. **Экспедиторы подают ставки:**
   - Видят список открытых грузов
   - Могут подать несколько ставок на один груз
   - Видят заблюренные ставки конкурентов (без деталей)

3. **Импортер закрывает груз:**
   - После дедлайна или по решению
   - Все ставки становятся видны всем участникам
   - Можно сравнить предложения и выбрать лучшее

## API Endpoints

### Аутентификация
- `POST /api/auth/register/forwarder` - Регистрация экспедитора
- `POST /api/auth/register/importer` - Регистрация импортера
- `POST /api/auth/login` - Вход
- `GET /api/auth/me` - Получить текущего пользователя

### Управление пользователями (только импортер)
- `GET /api/users/forwarders/pending` - Список ожидающих активации
- `GET /api/users/forwarders` - Все экспедиторы
- `PATCH /api/users/forwarders/:id/status` - Изменить статус экспедитора

### Грузы
- `POST /api/shipments` - Создать груз (только импортер)
- `GET /api/shipments` - Список грузов
- `GET /api/shipments/:id` - Детали груза
- `PATCH /api/shipments/:id` - Обновить груз (только импортер)
- `POST /api/shipments/:id/close` - Закрыть груз (только импортер)
- `DELETE /api/shipments/:id` - Удалить груз (только импортер)

### Ставки
- `POST /api/bids` - Создать ставку (только экспедитор)
- `GET /api/bids/my` - Мои ставки (только экспедитор)
- `GET /api/bids/:id` - Детали ставки
- `PATCH /api/bids/:id` - Обновить ставку (только экспедитор)
- `DELETE /api/bids/:id` - Удалить ставку (только экспедитор)

## Дополнительная информация

### Безопасность

- Пароли хешируются с помощью bcryptjs
- JWT токены для аутентификации
- Защита маршрутов по ролям (импортер/экспедитор)
- Валидация данных на сервере с помощью Zod

### Особенности реализации

- **Заблюренные ставки:** Экспедиторы видят количество ставок конкурентов, но не детали до закрытия груза
- **Множественные ставки:** Экспедитор может подать несколько ставок на один груз (например, для разных видов транспорта)
- **Автоматический расчет:** Итоговая стоимость с НДС рассчитывается автоматически
- **Статусы:** Грузы имеют статусы OPEN/CLOSED, экспедиторы - PENDING_ACTIVATION/ACTIVE/REJECTED/SUSPENDED
